# Projet M2L

Un projet web/mobile fait en deuxième année de BTS.

Il a été fait en Flutter Dart pour le front et Node pour le back.
Node est utilisé en tant qu'API.

Avec ce projet, il y a une gestion de comptes où seuls les admins peuvent accéder.

En tant qu'admin, on peut :
    - Voir les différents articles
    - Ajouter / Modifier / Supprimer un article

Il y a un README.md dans backend, bdd et frontend pour expliquer comment mettre le projet en place.
