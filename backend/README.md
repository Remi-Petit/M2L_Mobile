## Backend Node JS

API pour le frontend.

## Aller dans le bon dossier

cd ./backend

## Installer les dépendances

```cmd
npm install
```

## Lancer le serveur

```cmd
npm run dev
```

## A savoir

Dans /config, il faut mettre le fichier ".env" avec votre configuration.
Vous avez un exemple de configuration avec "/config/dev.env".
